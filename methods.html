Methods and results

When does an additional EEG feature improve post-view immersion prediction? This pilot compares three fixed feature sets on an explicitly paired sample.

Alignment audit

The released preprocessing code filters recordings before assigning EEG indices. This makes viewing order an insufficient guarantee of alignment. We matched item IDs, timestamps, viewing order and immersion labels to the authors’ benchmark, then matched each complete 310-value EEG vector exactly to the feature file.

91 complete rows from participant 01 pass this check. The final benchmark row is incomplete. The earlier 30-participant comparison has been retired from the homepage because its remaining mappings are unverified.

Chronological holdout

Of the 91 verified clips, the first 63 form the development set and the final 28 form the test set. Within development, 47 clips fit the candidate models and 16 select ridge regularization from 0.1, 1, 10 and 100. Each selected model is refit on all 63 development clips. Standardization is fitted on the corresponding training subset. Predictions are clipped to the questionnaire range [1, 5].

Behavior includes watch fraction, video duration and like status. The summary condition adds across-channel means and standard deviations for five bands. The channel condition retains all 62 × 5 values. Both EEG conditions have higher test error in this sample.

The sample covers one participant. Upstream EEG normalization uses the full recording, and viewing behavior is observed during the clip. These results concern offline post-view prediction. Long-term recommendation value and within-video affect changes require separate measurements.
